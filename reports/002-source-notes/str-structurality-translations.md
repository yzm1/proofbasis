## S1. Jeřábek, "The ubiquity of conservative translations"
- Bib: Emil Jeřábek, The ubiquity of conservative translations. Published Review of Symbolic Logic 5(4) 2012 (journal data UNVERIFIED-from-document; the arXiv text does not print journal data).
- Retrieved: https://arxiv.org/pdf/1108.6263v2 (arXiv:1108.6263v2 [math.LO], 31 Jul 2012; preprint; page numbers = arXiv PDF pages).
- Status: VERIFIED_SOURCE.
- Def 2.1 (p.2): deductive system = any set F with Tarski consequence (reflexivity, monotonicity, cut); "finitary" (iv). "Propositional logic" additionally needs F a free algebra and
  "(v) Γ ⊢ ϕ implies σ(Γ) ⊢ σ(ϕ) for every substitution σ, where as usual, a substitution is a homomorphism of free algebras." (p.3) -- i.e. structurality of the CONSEQUENCE RELATION is required of the target (CPC), NOT of the source and NOT of the translation.
- Def 2.2 (p.3): "A translation from a deductive system L0 = ⟨F0, ⊢0⟩ to a deductive system L1 = ⟨F1, ⊢1⟩ is a function f : F0 → F1 such that Γ ⊢0 ϕ ⇒ f(Γ) ⊢1 f(ϕ) ... The translation f is conservative ... if Γ ⊢0 ϕ ⇔ f(Γ) ⊢1 f(ϕ)."
- Intro (p.1), verbatim: "This notion of a conservative translation is still very general (perhaps too general): for instance, translations are not required to respect the structure of formulas in any way, to be computable, or to preserve any properties of the logic."
- Def 2.3 (p.3) "most general": for every translation g there is a substitution σ with g(ϕ) ⊣⊢1 σ(f(ϕ)).
- Theorem 2.4 (p.3), verbatim: "For every finitary deductive system L = ⟨F, ⊢⟩ over a countable set of formulas F, there exists a conservative most general translation f : L →c CPC. If ⊢ is decidable, then f is computable. In general, f is Turing equivalent to (the finitary fragment of) ⊢."
- Theorem 2.6 (p.4): multiple-conclusion version into CPCm, for finitary CONSISTENT systems.
- Construction (proof of 2.6, pp.4-5): enumerate F = {α_n}; f(α_n) := β_n := γ_n ∨ p_n ∧ δ_n, where p_n is the n-th propositional variable (one FRESH variable per enumerated source formula) and γ_n, δ_n are big disjunctions/conjunctions over all finite X,Y ⊆ n with α_X ⊢ α_n, α_Y (resp. α_X, α_n ⊢ α_Y). So the translation of α_n is built from the consequence relation itself (oracle for ⊢), indexed by an enumeration -- NOT by the syntactic structure of α_n.
- Remark 2.8 (p.6): size of f(ϕ) for |ϕ| = n is 2^{2^{O(n)}}; computable in time 2^{2^{O(n)}} t(2^{O(n)}) if ⊢ in time t.
- Def 3.1 (p.7) universal: L ≤c L0 for every finitary deductive system L over countably many formulas. Obs 3.2(ii): "L0 is universal iff CPC ≤c L0."
- Theorem 3.10 (p.11), verbatim: "A deductive system is universal whenever it conservatively extends a deductive system L0 such that (i) FL↾→,←,∧ ⊆ L0 ⊆ CPC↾→,←,∧, or (ii) FLe↾→,∧ ⊆ L0 ⊆ CPC↾→,∧, or (iii) FLew↾→ = BCK ⊆ L0 ⊆ CPC↾→."
- Example 3.3 (p.7): K (Kleene with constants) universal; LP not universal. Theorem 3.6 (p.9): "The fragment CPC↾B is universal if and only if → is definable from B." Note the CPC→K translation in Ex. 3.3(i) is CNF-normalisation (not compositional), the CPC↾M→LP translation is a substitution σ(p)=p∧¬p (structural!), the CPC→CPC↾→ translation is f(ϕ) ≈ ϕ∨q with a spare variable q (formula-wise, uses a Hilbert-hotel renaming).
- Remark 3.7 (p.10): "universality does not have much to do with abstract algebraic properties of the logic".
- Conclusion (p.14), verbatim: "these results show that the mere existence of a conservative translation of one logic into another without further restrictions does not provide useful information on the relationship of the two logics, and a more refined criterion is needed to formalize the intuitive notion of translatability."
- Jeřábek does NOT state (anywhere in the arXiv text; grep for compositional/grammatical/schematic/structur) any theorem about what fails under compositional/grammatical translations. No statement about IPC→CPC grammatical non-existence in this paper.
- Def 3.4 (p.8) also gives clone definition (used in S5): "A clone on a set X is a set of finitary operations on X which is closed under composition and contains all projections. ... if B is a set of Boolean functions, then definable functions in CPC↾B are exactly the functions from [B], hence clones on {0, 1} are in 1–1 correspondence with fragments of CPC considered up to term equivalence."
- INFERENCE: Jeřábek's universal translation is exactly an "interpreter/flattening" encoding of the same kind as MDT Prop 2.25 (a fresh atom p_n per source formula, wrapped in a formula computed by querying ⊢). It is not compositional: f(ϕ∧ψ) is not a function of f(ϕ), f(ψ). His own conclusion concedes that bare conservative translation is uninformative. So: ubiquity is a theorem about NON-structural translations; it does not, by itself, survive a compositionality requirement. Whether some weaker universality survives compositionality is NOT addressed by the source (open from this source's standpoint).
- Relevance: F02 (strong): bare "derivability preserved and reflected" (R1) admits trivial universal encodings for every countable finitary logic into CPC; R1 alone is vacuous. F09: blowup 2^{2^{O(n)}}. F08: Thm 3.6 shows that universality of CPC fragments depends only on the generated clone (→ ∈ [B]), i.e. basis-invariant.

## S7. Mossakowski–Diaconescu–Tarlecki, "What is a logic translation?" (local text)
- File: scratchpad/dl/rwl/mdt.txt (header: Logica Universalis, "c 2009 Birkhäuser Verlag Basel/Switzerland", pages "1–29" in that version = preprint/author version; the local text was retrieved by another agent).
- Status: VERIFIED_SOURCE (local text).
- Def 2.3 (p.3): ER morphism = function α: S1→S2 with Γ ⊢1 ϕ ⇒ α(Γ) ⊢2 α(ϕ); conservative if converse holds. Footnote 2: "Prawitz and Malmnäs [43] also use a more permissive notion of conservative translation where the equivalence is only required for Γ = ∅."
- §2.1 (p.4), verbatim: "A common requirement on translations (e.g. adopted by Wojcicki [48] and made explicit by Epstein and Krajewski [16]) is that they are schematic or grammatical [16], which means that they preserve the algebraic structure of the sentences — in other words, they are defined inductively over the structure of the sentences in the source ER. However, this preservation requirement rules out e.g. the standard translation of modal logic to first-order logic, which adds a quantifier at the very top. [16] lists other translations that are not schematic."
- Prop 2.25 (p.10): flattening into PHCL with a fresh variable α(ϕ) per sentence and ∆ = all Horn clauses α(ϕ1)∧…∧α(ϕn)→α(ϕ) with {ϕ1..ϕn} ⊢ ϕ (a "simple theoroidal" morphism: the whole consequence relation goes into the theory ∆). Cor 2.26: plain conservative embedding into CPLω (infinitary conjunction).
- Conclusion (p.~27), verbatim: "An interesting open question is the formalisation of “structurality” of translations between logics, such that translations flattening out the structure (like that in Prop. 2.25) are ruled out. However, the notions studied in the literature so far [48, 9] are clearly too limited here, as they focus on propositional connectives only. A proper notion would have to take into account also binding structures like quantification."
- References identified: [48] R. Wójcicki, "On reconstructability of the classical propositional logic into intuitionistic logic", Bull. Acad. Polon. Sci. Sér. Sci. Math. Astronom. Phys. 18:421–424, 1970. [9] C. Caleiro and R. Gonçalves, "Equipollent logical systems", in J.-Y. Béziau (ed.), Logica Universalis, pp. 99–112, Birkhäuser, 2005. Also [16] R. L. Epstein, The Semantic Foundations of Logic Vol. 1: Propositional Logics, Kluwer 1990 (MDT's text attributes "schematic/grammatical" to Epstein and Krajewski [16]).
- INFERENCE: MDT themselves (a) identify structurality as the property that should exclude Prop 2.25, (b) flag it as OPEN, (c) give a concrete counterexample to naive structurality as a criterion of legitimacy: the standard translation of modal logic into FOL is non-schematic (outermost quantifier). So "require schematic translations" would also exclude legitimate translations -- directly against hypothesis part (b) unless the notion is generalised (e.g. compositional up to a top-level wrapper / signature-indexed, binding-aware).
- INFERENCE (source item 7): yes, MDT's own target notion of structurality is meant to exclude Prop 2.25, but they say no adequate notion existed (as of 2009) beyond propositional ones [48, 9].

## S3. Pelletier & Urquhart, "Synonymous logics" (+ correction)
- Bib: F. J. Pelletier, A. Urquhart, Synonymous Logics, J. Philosophical Logic 32 (2003) 259–285 (journal data as printed in reference [2] of the correction and [6] of Caleiro–Gonçalves).
- Retrieved: https://sites.ualberta.ca/~francisp/papers/PellUrq.pdf (link from Pelletier's homepage; PREPRINT dated "October 11, 2001"; page numbers below = preprint page numbers printed in the text, not journal pages). Status: VERIFIED_SOURCE (preprint).
- Correction: F. J. Pelletier, A. Urquhart, "Synonymous Logics: A Correction", preprint dated August 25, 2006, retrieved https://sites.ualberta.ca/~francisp/papers/PellUrqcorrection.pdf (published J. Phil. Logic 37(1) 2008, 95–100 per search-engine/PhilPapers listing — UNVERIFIED from document). Status: VERIFIED_SOURCE (preprint).
- Translation scheme (p.3–6), verbatim: "The notion of translation that we define in the next paragraphs is essentially the same as the concept of schematic interpretation of Prawitz and Malmnäs [Prawitz and Malmnäs, 1968]. A similar definition (though given in the context of logics defined by consequence relations) is given by Ryszard Wójcicki [Wójcicki, 1988, p. 69]." Then: "A translation scheme is an assignment ... 1. Every variable Pi in L1 is assigned a formula Ai in L2; 2. If f is a connective in L1, then to the formula f(π1,…,πk) we assign a formula B of L2(P), where B contains only parameters from π1,…,πk." Translation determined by scheme: "(Pi)^t = Ai; [f(A1,…,Ak)]^t = B[A1^t/π1,…,Ak^t/πk]" (p.6). "simple" = identity on variables and B contains no variables other than the parameters (p.6). Logics assumed "given by axiom schemes and schematic rules; thus all logics will be closed under the rule of uniform substitution" (p.3).
- Sound / exact (p.6): "sound if the translation A^t is provable in S2 whenever A is provable in S1, and exact if ... if and only if" — NOTE: theoremhood only, not consequence relations.
- Example 2.1 (p.4): CPC over {∧,→,↔,¬} vs {∨,¬}: schematic translations both ways; p.4–5 notes potential EXPONENTIAL blowup of the ↔ clause ("we shall ignore the question of the efficiency of translations"; refers to Krajíček 1996 for an indirect translation avoiding blowup).
- Translational equivalence (p.7): schemes t1,t2, both sound, (A^{t1})^{t2} ↔ A theorem of S1 and conversely; requires a shared equivalence connective ↔ with congruence rules (equivalential logics). Synonymy (p.8): common definitional extension. Theorem 2.6 (p.9): "Two systems are synonymous if and only if they are translationally equivalent." (for simple schemes).
- Invariants: Cor 3.2 (p.12): "The number of non-isomorphic (reduced) algebraic models of given cardinality is a translation invariant." Thm 4.4 (p.16): proper normal sublogic pairs with f.m.p. are not translationally equivalent. Thm 4.5 (p.16): "The logics K, T, B, S4, S5 are all distinct from the point of view of translational equivalence." Positive: Lenzen (Ex 2.7) S4.4 ≡ KD45; ECNM ≡ T.
- Correction (2006 preprint): original Thm 4.7 (mutual exact translations without translational equivalence) had a "fatal mistake" found by Humberstone; new example Thm 2.1: logics L_X, L_Y with X={4^k}, Y={2·4^k}: "not translationally equivalent, although there are exact translations from L1 into L2 and from L2 into L1" (proof via 28 vs 29 two-element frames). Correction also cites Zolin, "Embeddings of propositional monomodal logics", Logic J. IGPL 8 (2000) 861–882, describing it as proving "the impossiblity of embedding certain strong modal logics like S5 into weak logics such as K" (SECONDARY_ONLY; Zolin NOT_ACCESSED; the precise translation notion Zolin uses is unverified).
- INFERENCE: P&U schemes are compositional (connective ↦ fixed context), so they exclude MDT 2.25-style flattening (a compound formula must be translated by plugging translations of its immediate subformulas into a fixed context). Under this notion mutual exact translatability is strictly weaker than synonymy — gives a presentation-invariant equivalence finer than "inter-translatable". If Zolin's result is about schematic embeddings (UNVERIFIED), then S5 ↪ K fails schematically while Jeřábek Thm 3.10 gives S5 ≤c K non-schematically (K extends CPC hence is universal) — a concrete case where ubiquity does NOT survive structurality.

## S4. Structurality à la Łoś–Suszko (SECONDARY)
- Primary: J. Łoś, R. Suszko, "Remarks on sentential logics", Indagationes Mathematicae (Proceedings) 61 (1958) 177–183, doi:10.1016/S1385-7258(58)50024-9 (bib data as printed in SEP bibliography). Status: NOT_ACCESSED (primary).
- Retrieved SECONDARY: R. Jansana, "Algebraic Propositional Logic", Stanford Encyclopedia of Philosophy, first published Dec 12, 2016, substantive revision May 20, 2022; https://plato.stanford.edu/entries/logic-algebraic-propositional/ (§ on logic systems). Status: VERIFIED_SOURCE for the secondary statement.
- Verbatim: "A logic system ... is given by a language L and a consequence relation ⊢ on the set of formulas of L that is formal in the sense that for every substitution σ, every set of formulas Γ and every formula ϕ, if Γ ⊢ ϕ, then σ[Γ] ⊢ σ(ϕ) ... The consequence relations on the set of formulas of a language that satisfy this property are called structural and also substitution-invariant in the literature. They were considered for the first time in Łoś & Suszko 1958."
- Substitution = map σ on variables extended uniquely by σ(∗ϕ1…ϕn) = ∗σ(ϕ1)…σ(ϕn) (i.e. an endomorphism of the formula algebra).
- Same entry, algebraizability: translations formula→equations "given by" a set of equations Eq(p) "in one variable" and equations→formulas by Δ(p,q) "in two variables"; L algebraizable iff Γ ⊢ ϕ ⟺ Eq(Γ) ⊨_K Eq(ϕ), plus mutual inverse conditions. These translations are structural by construction (defined by substitution into a fixed one-/two-variable template), and are independent of any anti-interpreter motivation (Blok–Pigozzi algebraization).
- INFERENCE: Łoś–Suszko structurality is a property of a consequence relation, not of a translation. Jeřábek requires it of the TARGET (Def 2.1(v)) yet his translations are not structural. The translation-level analogue ("t∘σ = σ^t∘t") must be stated separately; see the adversarial analysis below.

Status: VERIFIED_SOURCE (secondary survey of Post).
- Verbatim (§1.3, p.4): "We say a set of Boolean functions B is a clone (or, B is closed) if B = [B], i. e., no new functions can be derived from compositions of functions from B ∪ {id}. Every set B0 ⊆ B with [B0] = B is called a base (or basis) of B." "[B] ... superposition is equivalent to arbitrary composition of Boolean functions and introduction of fictive variables."
- Fig. 1: BF (all Boolean functions) listed with base {and, not}; R0 base {and, xor}; M base {and, or, c0, c1}; S0 base {imp}.
- Post's completeness criterion (p.~5): five maximal clones R0, R1, M, D, L; "[B] = BF ... One just has to make sure that f (or B) is not contained in one of Post's classes." Example 1.3: nand ∉ R0,R1,M,D,L, "we conclude that [nand] = BF".
- Jeřábek Def 3.4 (VERIFIED): clone = closed under composition + all projections; fragments CPC↾B "considered up to term equivalence" are in 1–1 correspondence with clones on {0,1}. Lemma 3.5: → ∉ [B] iff B ⊆ P0, D, A, or M. Thm 3.6: CPC↾B universal iff → ∈ [B].
- INFERENCE: {nand} and {and, not} are both bases of BF with disjoint primitive sets (nor likewise, by the same Post criterion or duality — inference, not quoted), so NO single operation belongs to every basis; the presentation-invariant object is the clone [B] (equivalently the fragment up to term-equivalence/definitional equivalence), not the primitive set or its cardinality. Primitive counts are not invariant ({nand}: 1; {and,not}: 2; same clone). F08 confirmed in the simplest case.

## S6. Caleiro & Gonçalves, "Equipollent logical systems"
- Bib: C. Caleiro, R. Gonçalves, Equipollent logical systems, in J.-Y. Béziau (ed.), Logica Universalis, Birkhäuser, pp. 99–112 (2005 per MDT [9]; search results list 2007 2nd edition — UNVERIFIED which edition).
- Retrieved: http://sqig.math.ist.utl.pt/pub/CaleiroC/05-CG-equipollence.pdf (author preprint; page numbers = preprint pages 1–14). Status: VERIFIED_SOURCE.
- Def 2.1–2.4 (pp.3–4): signature Σ (propositional variables included in Σ0); derived connective = λξ1…ξk.ϕ; "Definition 2.4. Given signatures Σ1 and Σ2, a signature morphism h : Σ1 → Σ2 is an N-indexed family of functions h = {h^n : Σ1^n → DC^n_Σ2}." Free extension h(c(ϕ1,…,ϕn)) = h^n(c)(h(ϕ1),…,h(ϕn)); "A translation function h that satisfies the above requirements will be dubbed uniform."
- Def 2.3 note: "For the sake of generality, we do not require here the consequence operator to be finitary, or even structural."
- Def 2.5: logical system morphism = signature morphism with h[Φ^⊢1] ⊆ h[Φ]^⊢2.
- Def 4.1 equipollent: Log-morphisms h, g whose induced theory-space maps are mutually inverse isomorphisms. Prop 4.3: equivalently ϕ ≡L1 g(h(ϕ)) and γ ≡L2 h(g(γ)).
- Against non-uniform maps (p.7), verbatim: "Either one does not require the language to bear any structure at all, in which case a simple translation function would make perfect sense, or else one should not neglect this structure when translating formulas across logical systems. Still, if we choose to simply ignore the way LΣ is build from the signature Σ, then we can as well assume that the language is build from a new signature Ω where ... Ω0 = LΣ and Ωn = ∅ for every n > 0 ... Nevertheless, we maintain that translations across logical systems should be effective, to a certain extent, and therefore some kind of uniformity must be required".
- Theory-space isomorphism alone too weak (p.9): LTL fragment with {¬,X,⇒} vs with G have isomorphic theory spaces though "in L1 there is no single formula with the same expressive power of Gϕ".
- Relation to P&U (pp.11–12): translational equivalence ⇒ equipollence; they coincide for equivalential logics with shared biconditional satisfying deduction theorem; converse open in general.
- INFERENCE: CG's uniformity is independently motivated (effectivity; respecting declared syntax), predates/does not mention interpreters, and excludes MDT 2.25. BUT their Ω-remark exposes a loophole: uniformity is relative to the declared signature — re-declaring every formula as an atom (Ω0 = LΣ) makes every function uniform. So structurality only has teeth if the source's constructor signature (incl. binders) is fixed independently of the encoding.

## Adversarial analysis (all INFERENCE / informal arguments, not machine-checked)
A1. Weak structurality does NOT exclude interpreters. Define "weakly structural": for every source substitution σ there is a target substitution σ* with t(σϕ) ≡ σ*(t ϕ) for all ϕ.
  - MDT 2.25 flattening: set σ*(α(ϕ)) := α(σϕ) for every target variable α(ϕ). Then t(σϕ) = α(σϕ) = σ*(α(ϕ)) syntactically; and if the source ER is structural, σ*(∆) ⊆ ∆. So flattening is weakly structural (indeed equivariant) whenever the source is.
  - Jeřábek Thm 2.4: if L is structural and σ a substitution, f∘σ is a translation L → CPC (Γ ⊢ ϕ ⇒ σΓ ⊢ σϕ ⇒ fσΓ ⊢CPC fσϕ). By most-generality (Def 2.3) there is τ with f(σϕ) ⊣⊢CPC τ(f(ϕ)) for all ϕ. So Jeřábek's universal translation commutes with substitution up to CPC-equivalence.
  => "commutes with substitution" in the existential sense is satisfied by both interpreter constructions. The criterion that bites is the STRONG one: the target substitution must be determined by σ on source variables only, with t(ϕ) built from t(variables) by fixed contexts (P&U translation scheme / CG uniform morphism / clone homomorphism). Hypothesis (a) holds only for the strong (compositional/uniform) reading.
A2. Strong structurality kills Jeřábek-style ubiquity in at least one standard case (informal argument): CPC is locally finite (2^{2^m} classes in m variables). A uniform/schematic t maps all formulas in variables p1..pk to formulas in the finitely many variables occurring in t(p1),…,t(pk). If t is conservative in Jeřábek's sense then ϕ ⊣⊢ ψ iff tϕ ⊣⊢ tψ, so the source has finitely many interderivability classes in k variables. IPC has infinitely many in one variable (Rieger–Nishimura; UNVERIFIED-MEMORY, standard), so there is NO schematic conservative translation of IPC into CPC, although Jeřábek gives a non-schematic one. Same argument excludes any non-locally-finite logic (e.g. K, S4) into any locally finite target. Status: informal argument; should be checked/cited (Epstein 1990 / Prawitz–Malmnäs 1968 reportedly discuss grammatical non-embeddability — NOT_ACCESSED).
A3. Strong structurality also excludes legitimate translations: MDT §2.1 — the standard translation of modal logic into FOL "adds a quantifier at the very top" and is not schematic; P&U mention Thomason's tense→modal translation is "very close to, but not identical with" their scheme. Also Jeřábek's CPC→K translation (CNF) is non-compositional though innocuous. So naive schematicity is not tailored only against interpreters; it over-excludes. A repair would allow (i) a compositional core plus a fixed top-level wrapper (still substitution-commuting in the strong sense when the wrapper is a fixed one-variable context, like Blok–Pigozzi Eq(p)), and (ii) binder-aware compositionality (MDT: open).
A4. Structurality is of independent pedigree: Łoś–Suszko 1958 (consequence), Prawitz–Malmnäs 1968 "schematic interpretation", Wójcicki 1970/1988, Epstein 1990 "grammatical", Blok–Pigozzi algebraization (one-variable defining equations), CG "uniform" (effectivity). None is motivated by excluding interpreters. Supports hypothesis (b) at the level of motivation; but A3 shows it is not neutral either.
A5. Invariant basis comparison: clone [B] (Boolean case), definitional/term equivalence, synonymy (P&U), equipollence (CG). Primitive counts are not invariant. Invariants usable as tests: number of reduced algebraic models per cardinality (P&U Cor 3.2); mutual exact translatability is strictly weaker than synonymy (P&U correction). All these are FORMULA-level; none addresses proof identity, proof-construction operations, or binders.
A6. Relevance to ProofBasis: R1 (derivability preserve+reflect) alone is vacuous (Jeřábek). Adding "commutes with substitution" in the weak sense is still vacuous (A1). The strong compositional requirement is the first that has teeth, but it must be relative to an independently fixed syntax (CG loophole), must handle binders (MDT open problem), and over-excludes standard translations (A3). F08 confirmed at the Boolean level: bases are non-canonical; only the generated clone is invariant.
