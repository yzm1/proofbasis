## F1 — FATAL (to executive item 4, §6.1, and "Failed approach 1"): the Lindenbaum-matrix interpreter does not pass D2. It fails T3 (SN and HOM) at generic formula metavariables, for exactly the reason report 002 already gave in L-g and I-C.

**Passage (§6.1).** "SN holds syntactically. The substituted environment items ∃!x ⌜θ⌝(x) are E-provable." Also: "D2's T4 does not separate deriving from importing at R1."

**Argument.**
- 002's SN requires F to be *defined on all schematic derivations*, with F(d[θ]) ≡ F(d)[⌜θ⌝], including at formula metavariables (002 §2.3, T3).
- In the matrix interpreter, the Horn item for an axiom applies only when the two occurrences of a repeated metavariable have the *same* witness. That requires ∃!x⌜X⌝(x).
- For a metavariable X, which goes to a predicate letter or metavariable X(·), there is no such environment item. "Axioms about specific atoms" (002 §2.2) cover atoms, not metavariables.

**Concrete countermodel (VERIFIED by finite enumeration, `ref/lind_enum.py`).**
- Domain {0,1}. F_→(0,0)=0, F_→(0,1)=1, F_→(1,0)=0, F_→(1,1)=0. D = {0}. P_p = {0}.
- This structure satisfies totality, functionality, ∃!P_p, the Horn item ∀ab(D(F(a,F(b,a)))), and MP-closure.
- With X = {0,1} and Y = {0}, the element 1 = F(0,F(0,1)) satisfies ⌜X→(Y→X)⌝ but is not in D.
- So E ⊬ W(X→(Y→X)). F cannot be defined on the schematic axiom by a fixed template.

**Consequences.**
- After θ, the item ∃!x⌜θ⌝(x) has to be *proved by induction on θ*. That is θ-dependent. It is neither ⌜θ⌝ plugged into a fixed template nor an environment item.
- The MP template has the same defect: it needs ∃x⌜A⌝(x) at generic A.
- The draft's own D-2 remark ("Without them, the occurrences of p … are translated independently and the interpreter loses soundness") concedes the mechanism.
- So D2 *does* exclude this interpreter. It does so through T1 and T3 (SN at metavariables), not T4.
- The executive verdict item 4, §6.2 D-2's framing, and §7 "Failed approach 1" must be withdrawn or restated.

**What survives (INFERENCE).**
- T4 has no bite for a first-order core. Under T1, formulas go to A-formulas, and a first-order item cannot quantify over formulas or propositions, so *every* first-order environment passes T4. That includes the ST environment.
- So the draft's dichotomy, "either admits this interpreter … or excludes ST as well", is mis-diagnosed. For FOL cores, D2's anti-importing content is carried entirely by T1+T3.
- That is a legitimate, smaller finding about 002.

**Fix.**
- Replace §6.1 with: "T4 is vacuous for FOL cores. The matrix interpreter is excluded by SN at metavariables (as in 002 L-g). Whether a matrix-style interpreter with metavariables sent to a 'stable sort' could pass D2 is open."
- Or exhibit an interpreter that actually passes SN at metavariables. One attempt sends formulas to individual *terms* f_c(t_A,t_B). That fixes SN but fails T1, since it is formulas-as-data, as in B1.

## F2 — MAJOR: D-6 (extra vocabulary, PC classes) is not OPEN. It collapses to plain CRR by the Goldblatt–Hodkinson–Venema strengthening of Fine's theorem, which is in the draft's own source.

**Passages.**
- §6.2 D-6: "OPEN … Whether this captures GL or K+M was not determined."
- Disclosed loophole 2: "D-6 for logics other than K+M."
- O2: "OPEN for GL."

**Argument.**
- GHV (erdos.txt, p. 4–5, statement (3); VERIFIED) states: "if a variety V is generated by some ultraproducts-closed class of structures, then it is generated by an elementary class …".
- A PC class (the {R_∇}-reducts of the models of E, where E uses extra symbols or sorts but no P_i) is closed under ultraproducts, because reducts commute with ultraproducts (standard; INFERENCE).
- By the draft's own Theorem 1 argument, L = Log(PC class). Hence Var(L) is elementarily generated, so L = Log(some elementary class). L therefore has a plain CRR.
- So D-6 adds **nothing**. Every D-6-representable logic is already CRR-representable.
- GL is excluded under D-6. So are the Kripke-incomplete witnesses and every non-canonical logic.
- The draft's K+M inference is correct, but it is a special case of this.

**Fix.**
- Mark D-6 CLOSED, citing GHV (3) (and Goldblatt's original, which the GHV text cites as [19]).
- Remove loophole 2.
- Restrict O2 to D-4.

## F3 — MAJOR: Question T (§10) does not discriminate, and is very plausibly already answered by material in the project's own notes.

**Argument.**
1. **The one-point frame trivialises T.**
   - P = 1, with P(*,*;*) = 1, is a finite *symmetric* promonoidal category. Its Day convolution is (Set, ×), which is cartesian closed (INFERENCE, standard).
   - Faithfulness is monotone in the class of frames. So both (a) and (b) hold as soon as this single cartesian frame separates the proofs. The frame condition (symmetry) plays no role.
   - Analogy: this is the proof-level twin of the Makinson one-point-frame phenomenon (§5.3, row 2). It is not a correspondence.
2. **(b) is nearly settled already.**
   - The project's notes record Petrić–Zekić Prop. 6.5 (Kelly–Mac Lane): "Two terms of the same proper type are equal if and only if they induce the same links" (source notes S11; VERIFIED as recorded).
   - In unit-free IMLL every type is proper. So the free unit-free SMCC's proof identity *is* link-graph identity.
   - Separating distinct linkings in (Set, ×) is then routine. Distinct linkings give βη-distinct STLC×-normal terms. Friedman/Statman then give separation over infinite, or per pair finite, sets.
   - This is INFERENCE. Named gap: faithfulness of IMLL⁻ → STLC× (UNVERIFIED-MEMORY that it holds).
   - §10 point 4, "Whether finite Set-valued frames suffice is not known to this report", ignores S11.
3. **The fixture for (a) already exists.**
   - The sequent (s/s), s, (s\s) ⊢ s has two proofs, f(g x) and g(f x). Their link graphs differ, and P = 1 separates them for non-commuting f and g (INFERENCE, elementary).
   - "Must first be identified" is a five-minute task, not an open obligation.
4. **"Symmetric promonoidal" is structure, not a frame condition.** It is a choice of σ with σ² = 1 plus the hexagon conditions (INFERENCE). One P may carry several symmetries that interpret exchange differently. The categorified "R(x,y,z) → R(y,x,z)" is therefore not a property-to-rule correspondence.
5. **Technical inaccuracies.**
   - A unit-free promonoidal structure gives a *semigroupal* biclosed category.
   - Associativity isomorphisms require coherence (pentagon); the draft omits this.
   - "Yoneda is fully faithful, strong monoidal and closed" is right. The nLab text (VERIFIED) gives strong monoidal; preservation of internal homs is a correct informal calculation (INFERENCE).

**Fix.** Re-pose T as a *correspondence* question with the cartesian collapse excluded. Example: "the exchange morphism is interpretable as a *natural* transformation over all Day models on P iff P admits a symmetry; and the interpretation over the class of such P is faithful for S but *not* faithful for any proper quotient." Alternatively, demote T and first settle points 1–3 on paper.

## F5 — MAJOR: Proposition 7 (the trilemma) is not proved as stated, and its "U + A" row is mis-constructed.

**Passage.** "Consider schemes in which the Boolean base is fixed and atoms are unrestricted unary predicates. No such scheme has all three …" (PROVED HERE).

**Argument.**
- "Scheme" is unquantified. The proof covers only two cases:
  - C1-fixed ST (Theorem 5);
  - per-logic FO clauses with wrapper exactly ∀x and atom-free E, for completely incomplete L (Proposition 6).
- It does not cover other fixed wrappers, for example the relativised ∀x(D(x) → ⌜φ⌝(x)) that §6.1 itself uses.
- With a relativised wrapper, Proposition 6's step 5 breaks (INFERENCE).
  - The logic becomes that of matrices (A_M, ↑D^M), and its normal part is given by the largest open filter inside ↑D^M.
  - That filter need not be principal, because the f_∇ are only finitely additive, so the quotient BAO need not be complete.
- The row "U+A / drop N" says "E_L states, for every admissible X⃗, ∀x ST_x(σ)[X⃗]". As written, that E is **atom-free**.
  - It is a D-6 instance, so by F2 it yields only elementarily determined logics. It is *not* universal.
  - It fails preservation for σ[θ/p], because the ST of θ need not be admissible.
- To be universal, the construction needs two kinds of addition:
  - per-atom items ∃X∀x(P_i x ↔ x ε X). These are what actually violate N.
  - first-order closure axioms making the admissible sets closed under ∩, complement and ⟨R_∇⟩.
- After both additions it rests on general-frame completeness, which is UNVERIFIED-MEMORY here, as the draft admits.
- The row "U+N" via Makinson needs care:
  - The one-point frame is reflexive or irreflexive *depending on L*.
  - The polyadic generalisation is unverified. INFERENCE: it is true via 2-element BAOs.

**Fix.**
- State Proposition 7 for the explicit family "C1-or-per-logic FO clauses, wrapper ∀x, atom-free E".
- Prove only that.
- Rewrite row 1 with the per-atom and closure axioms.

## F7 — MINOR: Theorem 2 / C1 have hidden hypotheses.

1. **SN needs D_α to be "letter-pure".**
   - If the FO derivation D_α contains predicate letters P_q with q not in α (possible, e.g. via ⊥-elimination), then F(d)[⌜θ⌝] substitutes into those occurrences while F(d[θ]) does not. Syntactic SN then fails.
   - Fix: choose D_α cut-free (subformula property) or rename auxiliary letters apart.
2. **The Nec template's conclusion is not literally an ST image.**
   - C1's primitives are →, ⊥ and ∇ (diamond). The n-ary dual box in argument i is ¬∇(⊤,…,¬φ,…,⊤).
   - Its ST is not syntactically ∀y⃗(R x y⃗ → A(yᵢ)). The template needs fixed FO conversion steps. This is harmless but should be stated.
   - Only the unary case was checked.
3. **"Fixed by arity alone" presupposes the diamond-primitive convention.**
   - Goldblatt (p. 58, VERIFIED) writes n-ary operators as □(α₁,…,αₙ).
   - For box-primitive presentations, C1 must use ∀y⃗(R → ⋁ᵢ ST(φᵢ)). Otherwise the K axioms fail.
   - C1 should state that normal operators are taken as join-preserving.
4. **"Forced by C1–C3" (P) overstates.**
   - C1 *stipulates* the formula translation.
   - The derivation translation depends on a non-unique, non-constructively chosen D_α.
5. **"Many-sorted" in the core is inconsistent with C4.** C4 allows only {R_∇} and no extra sorts. Extra sorts would be D-6 (see F2).
