## Vosmaer, "A new version of an old modal incompleteness theorem"
- arXiv:1202.3268v1, 15 Feb 2012. The document itself is dated 10 Feb 2006 and headed "SUBMITTED TO THE BULLETIN OF THE SECTION OF LOGIC". Publication status unknown.
- Retrieved: https://arxiv.org/pdf/1202.3268. Status: VERIFIED_SOURCE (preprint).
- Abstract, VERBATIM: "Thomason [4] showed that a certain modal logic L ⊂ S4 is incomplete with respect to Kripke semantics. Later Gerson [2] showed that L is also incomplete with respect to neighborhood semantics. In this paper we show that L is in fact incomplete with respect to any class of complete Boolean algebras with operators, i.e. that it is completely incomplete."
- Definition of L (§2), VERBATIM: "Let L be the logic containing all propositional tautologies, A, B, C, D and E and closed under modus ponens, substitution and necessitation (this is the same logic as found in [4]). It is not hard to see that T ⊆ L ⊆ S4." So L is finitely axiomatized.
- Lemma 1, VERBATIM: "Let A be a complete BAO. If A |= L, then A |= F." Here F := □p → □²p. Lemma 3: F ∉ L. Theorem 4: "L is completely incomplete."
- Introduction, VERBATIM: "in 2003 Litak [3] showed that Fine's logic is in fact as he calls it completely incomplete". Reference [3] is T. Litak, "Modal Incompleteness Revisited", Studia Logica 73, pp. 1–15. The Litak paper was not accessed, so this is SECONDARY_ONLY.
- Reference [4], as printed: S.K. Thomason, "An incompleteness theorem in modal logic", Theoria 40 (1974) pp. 30–34. BvB instead print Theoria 40:150–158; this conflict is unresolved.
- Use in report 004: Proposition 6. For any atom-free first-order representation with arbitrary first-order connective clauses, the represented logic is the logic of a class of complete BAOs. So L has no such representation.
