## S1. Cousineau & Dowek, "Embedding Pure Type Systems in the lambda-Pi-calculus modulo"

- Bib: Denis Cousineau, Gilles Dowek. TLCA 2007, LNCS 4583, pp. (not checked). Springer chapter
  DOI as listed by Springer search result: 10.1007/978-3-540-73228-0_9 (seen only in a search-result URL,
  not printed on the retrieved document → treat DOI as SECONDARY_ONLY).
- Retrieved: https://arxiv.org/pdf/2310.12540 (arXiv:2310.12540v1, posted 19 Oct 2023; 21 pp.). This is an
  arXiv posting of the 2007 paper; I did NOT compare it line-by-line with the LNCS version. The
  author's homepage copy (lsv.fr/~dowek/Publi/tlca.pdf) failed (TLS hostname mismatch).
- Status: VERIFIED_SOURCE (arXiv version).

### Definitions
- Def 4 (λΠ-modulo): "Let Σ be a context and R a rewrite system in Σ. Let ≡βR be the congruence of terms
  generated by the rules of R and the rule β. The λΠ-calculus modulo R is the extension of the λΠ-calculus
  obtained by replacing the relation ≡β by ≡βR in the conversion rules".
- Def 6 (Functional): "⟨s1,s2⟩ ∈ A and ⟨s1,s3⟩ ∈ A implies s2 = s3; ⟨s1,s2,s3⟩ ∈ R and ⟨s1,s2,s4⟩ ∈ R implies s3 = s4".
- §4.1 the encoding: context ΣP has, per sort s, `Us : Type` and `εs : Us ⇒ Type`; per axiom ⟨s1,s2⟩ a
  constant `ṡ1 : Us2`; per rule ⟨s1,s2,s3⟩ a constant `Π̇⟨s1,s2,s3⟩`. Rewrite rules
  `εs2(ṡ1) → Us1` and `εs3(Π̇ X Y) → Πx:(εs1 X)(εs2 (Y x))`. NOTE: signature size is linear in |S|+|A|+|R|;
  for infinitely many sorts the signature is infinite.
- Def 7: translation |·| maps PTS λ to framework λ and PTS application to framework application
  ("|λx : A t| = λx : (εs |A|) |t|", "|t u| = |t| |u|"). This is the "shallow"/"computational" choice
  later criticised by Felicissimo (S4).

### Theorems (arXiv version numbering)
- Prop 1: "1. |(u/x)t| = (|u|/x)|t| ... 2. If t −→β u then |t| −→β |u|." (preserves substitution and β-steps)
- Prop 3 (Soundness): "If Γ ⊢ t : B in P then ‖Γ‖ ⊢ |t| : ‖B‖ in λΠP." Hypothesis: P functional.
- Prop 4: "If λΠP terminates then P terminates."
- §4.4 Prop 10: the reduction of λΠP is confluent "for any functional Pure Type System P".
- §5 NEGATIVE statement (verbatim): "We could attempt to prove that if the type ‖A‖ is inhabited in λΠP,
  then A is inhabited in P, and more precisely that if ... ‖Γ‖ ⊢ t : ‖A‖, then there exists a term u of P such
  that |u| = t and Γ ⊢ u : A. Unfortunately this property does not hold in general as shown by the following
  counterexamples." Example 4: polymorphic identity typable in the encoding of STLC; Example 5: Π̇ itself is
  not the translation of any term.
- Prop 13: "1. If A ≡β B, then ‖A‖ ≡ ‖B‖. 2. If C ≡ D, then C* ≡β D*. 3. If ‖A‖ ≡ ‖B‖, then A ≡β B."
  (type-level conversion preserved AND reflected.)
- Prop 14 (Conservativity): "If there exists a context Γ, a term A of P, and a term t, in weak η-long normal
  form, of λΠP, such that ‖Γ‖ ⊢ t : ‖A‖, Then there exists a term u of P such that |u| ≡ t and Γ ⊢ u : A."
- Theorem 1: "Let P be a functional Pure Type System, such that λΠP is terminating. The type ‖A‖ is inhabited
  by a closed term in λΠP if and only if the type A is inhabited by a closed term in P."
  Hypotheses: P functional; λΠP (the TARGET) terminating — an unproven assumption at the time (see S2/S4).
  Quantifier: closed inhabitants only (inhabitation-level, i.e. derivability).
- Remark 1: "not all terms of type A◦ correspond to proofs of A" — explicitly NO bijection on proofs.

### What is preserved / proof identity
- Preserved: typing (Prop 3), substitution, β-steps (Prop 1). Reflected: inhabitation (Thm 1, under
  termination of λΠP); type conversion (Prop 13.3).
- Proof identity: NOT a bijection. Conservativity is "|u| ≡ t" (up to framework conversion) for weak-η-long
  normal t only. Non-normal framework terms may not be translations. No statement that β-equivalence of
  proofs is reflected (only types).
- Machine vs environment: the λΠ-modulo kernel is fixed; ALL PTS-specific content (Us, εs, Π̇, rewrite
  rules) is in the signature ΣP + R, built per PTS.

### Relevance (INFERENCE)
- F01: This is a schema of finite (for finite S) signatures over one fixed kernel covering every functional
  PTS — a strong partial precedent for "fixed machine + environment". But the per-system content is in the
  environment, conservativity needed extra hypotheses, and no proof bijection.
- F03: The rewrite rules are the PTS's typing discipline (Π-formation/universe decoding) — they are
  object-logic inference content living in the environment.

## S1b. Assaf, "Conservativity of embeddings in the λΠ calculus modulo rewriting (long version)"

- Bib: Ali Assaf. Long version of TLCA 2015 paper (LIPIcs, TLCA 2015 art. 31 per search-result URL
  10.4230/LIPIcs.TLCA.2015.31 — SECONDARY_ONLY, not printed on retrieved arXiv text I checked).
- Retrieved: https://arxiv.org/pdf/1504.05038 (arXiv:1504.05038v2, 21 Apr 2015). VERIFIED_SOURCE.
- Abstract: "This result was previously only proved under the condition that the target system is normalizing.
  Our approach does not depend on this condition and therefore also works when the source system is not
  normalizing."
- Motivating hazard (p.2, Example 1.1): polymorphic identity |I| typable in λΠ/HOL though not in λHOL; the
  analogous PTS λU⁻ is inconsistent; "Is that enough to make λΠ/HOL inconsistent?"
- Intro: "if the embedding turns out to be inconsistent then checking proofs in the logical framework has very
  little benefit."
- Theorem 5.24 (Conservativity): "For any Γ-type A of λS, if there is a term N such that ‖Γ‖ ⊢λΠ/S N : ‖A‖Γ
  then there is a term M such that Γ ⊢λS M : A." Hypothesis: λS a functional PTS (FPTS), no
  normalization assumption. Method: minimal completion S* (Def 5.6) + reducibility (relative normalization).
- Conclusion: "The strong normalization of λΠ/S when λS is strongly normalizing is still an open problem."
  (as of 2015)
- Proof identity: inhabitation-level only; M is obtained after β-reduction of an inverse translation —
  no bijection, no statement about equivalence classes of proofs.

## S2. Assaf, Burel, Cauderlier, Delahaye, Dowek, Dubois, Gilbert, Halmagrand, Hermant, Saillard,
## "Dedukti: a Logical Framework based on the λΠ-Calculus Modulo Theory"

- Retrieved: https://arxiv.org/pdf/2311.07185 (arXiv:2311.07185v1, 13 Nov 2023; 36 pp.; headers say
  "Deducteam"; affiliations ~2016 — this is the long-circulating manuscript posted to arXiv in 2023).
  No DOI printed. VERIFIED_SOURCE.
- Systems claimed expressed (abstract): "constructive and classical predicate logic, Simple type theory,
  programming languages, Pure type systems, the Calculus of inductive constructions with universes, etc." and
  libraries from "Zenon, iProver, FoCaLiZe, HOL Light, and Matita". Sections: 4 constructive predicate logic &
  deduction modulo; 5 classical predicate logic, Zenon; 6 STT, HOL Light; 7 λ-calculus, ς-calculus, ML,
  FoCaLiZe; 8 CIC with universes, Matita. Conclusion lists library sizes (iProverModulo TPTP 38.1 MB,
  Zenon modulo Set Theory 595 MB, Focalide 1.89 MB, Holide 21.5 MB, Matita arithmetic 1.11 MB).

### Fixed kernel vs user-supplied content
- §3.1: "there are two kinds of constructs available in Dedukti: variable declaration and rewrite rule
  declaration. The only available constant at the root of a file is Type". So the kernel = λΠ typing +
  conversion modulo β ∪ user rules; EVERY logic is a user signature + user rewrite rules.

### What is required of user rules, and what is checked vs trusted
- §2.2.3: "Subject reduction ... does not hold in general in the λΠ-calculus modulo theory. However it does if we
  have the two following properties: well-typedness of rewrite rules and product compatibility".
- Lemma 4 (Subject Reduction, cites Thm 2.6.22 of Saillard thesis [65]): "Let Γ be a global context satisfying
  product compatibility and whose rewrite rules are well-typed. If Γ ⊢ t1 : T and t1 →βΓ t2 then Γ ⊢ t2 : T."
- §2.3: "proof-checking is not always decidable because ... the conversion sequence justifying A ≡βΓ B is not
  recorded in the conclusion. Thus, we need to restrict to effective subsystems ... terminating and confluent".
- §2.3.2: Definition 2 (well-typed rule) "quantifies over all possible substitutions, so is not effective. Thus,
  we need to under-approximate this notion" → sufficient condition via most general typing substitution;
  Lemma 7 (Thm 3.5.8 in [65]).
- Theorem 8 (Effectiveness, Thms 4.5.10 & 6.3.1 in [65]): "If Γ is a strongly well-formed context such that
  higher-order rewriting is confluent then Γ satisfies the subject reduction property. Moreover, if higher-order
  rewriting is terminating on well-typed terms, then typing is decidable."
- §3: "The typing algorithm relies on the confluence and termination of the higher-order rewrite system together
  with β-reduction".
- §3.1 (KEY, verbatim): "one can add as many rules as wanted for a given head symbol, as long as confluence is
  preserved. Checking confluence is out of the scope of Dedukti itself, and is a separate concern. To support
  confluence checking by external tools, an export feature towards the old TPDB format ... is available."
- §3.4 Guards: "Dedukti cannot check in general the validity of the guard ... since it is undecidable. Thus ...
  Dedukti checks, each time the rule is used, that the typing constraints are satisfied."
- => CHECKED by kernel: well-typedness of rules (sufficient syntactic criterion). NOT checked / TRUSTED:
  confluence, termination; and NOTHING about consistency or conservativity of the user theory — nothing
  prevents declaring an inhabitant of a falsity type (INFERENCE from the two-construct description above).

### PTS section (§8.1) and terminology
- Lemma 30 (Preservation of computation, Prop 1 in [32]): "If Γ ⊢ M : A and M −→β M′, then there exists N′ such
  that |M| −→β N′ ≡βΣ |M′|."
- Lemma 31 (Preservation of typing).
- "It is also conservative—that is, adequate—with respect to the original system." Lemma 32 (Conservativity,
  adequacy, [9]=Assaf 2015): "If Σ, ‖Γ‖ ⊢ M′ : ‖A‖, then there exists M such that Γ ⊢ M : A and |M| ≡βηΣ M′."
- NOTE (adversarial): this manuscript uses "adequate" as a synonym for "conservative", whereas Felicissimo
  (S4) uses adequacy = syntactic bijection and states prior Dedukti encodings lack it. Also Lemma 32 as stated
  ("|M| ≡βηΣ M′") is stronger than Assaf's Theorem 5.24 as I read it (which only asserts existence of M with
  Γ ⊢ M : A); I did not check whether Assaf's appendix proves the convertibility clause. Flag as possible
  overstatement — UNRESOLVED.
- Lemma 25 (ς-calculus shallow encoding) "preserves binding, typing, and the operational semantics".

### Relevance (INFERENCE)
- F01: Dedukti is an existing, implemented, fixed finite kernel used for many foundations; this directly
  threatens novelty of "fixed machine + environment". But it achieves this by putting the logic in the
  environment (signature + rules), which is exactly F03.
- F03: Confirmed in source: confluence and termination of user rules are trusted (out of the kernel's scope);
  consistency/conservativity of the theory are meta-theorems proven (or not) on paper per encoding.

## S3. Blanqui, Dowek, Grienenberger, Hondet, Thiré, "Some Axioms for Mathematics"

- Bib: FSCD 2021, LIPIcs 195, Article No. 20, pp. 20:1–20:19. DOI (printed): 10.4230/LIPIcs.FSCD.2021.20.
- Retrieved: https://drops.dagstuhl.de/storage/00lipics/lipics-vol195-fscd2021/LIPIcs.FSCD.2021.20/LIPIcs.FSCD.2021.20.pdf
  (publisher version). VERIFIED_SOURCE.
- Abstract: "We present such a theory, the theory U, where proofs of several logical systems can be expressed.
  Moreover, we identify a sub-theory of U corresponding to each of these systems, and prove that, when a proof
  in U uses only symbols of a sub-theory, then it is a proof in that sub-theory."
- Systems (p.1): "Minimal, Constructive, and Ecumenical predicate logic; Minimal, Constructive, and Ecumenical
  simple type theory; Simple type theory with predicate subtyping, prenex predicative polymorphism, or both;
  the Calculus of constructions, and the Calculus of constructions with prenex predicative polymorphism".
- Size (§3 end): "ΣU contains 38 declarations and RU 28 rules." — a FINITE signature.
- Def 1: "It is a theory if ↪βR is confluent on Λ(Σ), and every rule of R preserves typing in Σ, R."
- Def 3 (Fragment), Def 6 (Sub-theory), Theorem 7 (fragment theorem): "Let Σ0, R0 be a confluent system and Σ1, R1
  be a fragment of Σ0, R0 that preserves typing. If the judgement Γ ⊢0 t : D is derivable, Γ ∈ Λ(Σ1) and
  t ∈ Λ(Σ1), then there exists D′ ∈ Λ(Σ1) such that D ↪*0 D′ and the judgement Γ ⊢1 t : D′ is derivable."
- Corollary 8: same with D ∈ Λ(Σ1) gives Γ ⊢1 t : D.
- Theorem 9: "Every fragment Σ1, R1 of U (including U itself) is a theory, that is, is confluent and preserves
  typing." (confluence: orthogonal combinatory reduction system.)
- EXPLICIT LIMITATION (§4, verbatim): "This property implies that, if π is a proof of A in U and both A and π are
  in Λ(Σ1), then π is a proof of A in Σ1, R1, but it does not imply that if A is in Λ(Σ1) and A has a proof in U,
  then it has a proof in Σ1, R1." => NO conservativity of U over its sub-theories at the level of provability.
- §5: correspondence of sub-theories with standard systems is asserted ("This theory can be proven equivalent to
  more common formulations of ... [refs]") — NOT proven in this paper; Minimal STT/CoC claims cite other work.
  "classical predicate logic is not a sub-theory of the theory U" (handled via ecumenical logic).
- §3 / §5: object-level polymorphism "makes the theory U inconsistent", hence restricted to prenex.
- §5 CoC: "the formulation of the Calculus of constructions in λΠ/≡ is in fact a conservative extension of the
  original formulation" (x : Set ⊢ x : Set derivable) — i.e. the U-version is NOT identical to CoC.
- Not found in this paper: proof of consistency or termination of U as a whole; no proof-identity statement.
  (grep for normaliz/terminat/consisten found none beyond the above.)
- Conclusion: U is "a candidate for a universal theory" for HOL Light, Isabelle/HOL, HOL 4, Coq, Matita, Lean, PVS.
  Inductive types, universes etc. NOT in U ("can be complemented with other axioms").

### Relevance (INFERENCE)
- F01: U is the closest existing artefact to "one finite fixed object for many foundations": a single finite
  signature+rules (38 decl./28 rules) on a fixed kernel. However: (a) coverage excludes inductive types,
  universe hierarchies, classical logic per se; (b) correspondence to the standard systems is via (largely
  external) equivalence claims; (c) the fragment theorem is about syntactic restriction of the SAME proof
  term, not translation of proofs, and does not give provability-conservativity; (d) no proof-identity result.
- F03: U makes the "environment" fixed and finite — so the "trusted rules in the environment" objection
  becomes a one-time trust in 28 rules (confluence proven, type-preservation proven) rather than per-user rules.
  This is a serious precedent the project must engage with.

## S4. Felicissimo, "Adequate and Computational Encodings in the Logical Framework Dedukti"

- Bib: Thiago Felicissimo. FSCD 2022, LIPIcs 228, Art. 25. DOI (printed): 10.4230/LIPIcs.FSCD.2022.25.
- Retrieved: (a) DROPS publisher PDF; (b) full version https://arxiv.org/pdf/2205.02883 (v1, 5 May 2022,
  "long version of a paper accepted at FSCD 2022"). Theorem numbers below are from the arXiv long version.
  VERIFIED_SOURCE.
- Definition of adequacy (abstract): "an adequacy theorem – i.e., a bijection between terms in the encoded system
  and in its encoding."
- Negative claims about prior work (abstract/intro): "Dedukti encodings proposed until now do not feature an
  adequacy theorem ... Moreover, many of them also do not have a conservativity result, which compromises the
  ability of Dedukti to check proofs written in such encodings." Intro: "recent works such as [22], [17] and [14]
  have left conservativity as conjecture." p.2: "if conservativity does not hold then the fact that the
  translation of a proof is checked correct in Dedukti does not imply that this proof is correct."
- Diagnosis: traditional encodings represent object-λ/app by framework λ/app, so "redexes of the encoded system ...
  get confused with the β redexes of the framework".
- Conservativity vs adequacy: conservativity = "if the translation of a type is inhabited, then this type is
  inhabited"; adequacy = bijection (stronger; "adequate (and thus conservative)").
- Def 13 / Assumption 14 / Theorem 18 ("β is SN in Dedukti"): "If βR is confluent and R is arity-preserving,
  then β [framework β only] is SN".
- Theorem 19 (from [12]): for functional PTS, bijection Λ(Γ ⊢PTS _ : A) ≅ Λ(Γ′ ⊢EPTS _ : A′)/≡I.
- Theorem 45 (Conservativity): for Γ ⊢ A type and ⟦Γ⟧ ⊢DK M : T, "Γ ⊢ |NFβ(M)| : A and M ↪*β NFβ(M) ≡H ⟦|NFβ(M)|⟧".
- Def 42: ≡H = conversion by "hidden" steps on binder type annotations.
- Theorem 46 (Computational adequacy, verbatim modulo symbols): "We have a bijection Λ(Γ ⊢EPTS _ : A) ≅
  ΛNF(⟦Γ⟧ ⊢DK _ : T)/≡H given by ⟦−⟧ and |−|. It is compositional in the sense that ⟦−⟧ commutes with
  substitution. It is computational in the sense that M ↪* N iff ⟦M⟧ ↪* ⟦N⟧. Moreover, any M satisfying
  ⟦Γ⟧ ⊢DK M : T has such a β normal form."
  Hypotheses: functional EPTS (explicitly typed), including non-normalizing ones (conclusion: "even non
  terminating ones, such as the one with Type : Type"). Framework-β-normal forms, quotient by ≡H.
- Limitations stated: §8 infinite sorts need infinite signatures → internalised sort encoding; §9 "it is still an
  open problem for us to find a notion of morphism" between the two encodings; one "has to redo the work of
  Section 7"; §10 adequate encoding is ~16x slower to typecheck (Fermat's little theorem library benchmark).
  Conclusion: extension to inductive types, universe polymorphism etc. is future work.

### Proof identity (INFERENCE from Thm 46)
- This is the strongest result found: for functional EPTSs, encoded-system reduction is both preserved and
  reflected ("M ↪* N iff ⟦M⟧ ↪* ⟦N⟧") and terms correspond bijectively (mod ≡H, on framework-β-normal forms).
  Hence the encoded system's reduction/conversion (a candidate proof-identity congruence) is preserved and
  reflected — but only for this specific deep-ish encoding, with explicit type annotations, and only for
  PTS-like systems. It also shows that adequacy is achievable by encoding object binders through dedicated
  constants (LF-style), at a performance cost.

### Relevance (INFERENCE)
- F03 confirmed by primary sources: the environment's rewrite rules carry (i) logic-specific inference content
  and (ii) global metaproperties (confluence, termination) that are undecidable and not enforced by the kernel.
  The correctness of a Dedukti check of an encoded proof is relative to paper meta-theorems (conservativity)
  about that specific environment.

### S6b. Dowek, "Models and termination of proof reduction in the λΠ-calculus modulo theory"
- Retrieved https://arxiv.org/pdf/1501.06522 (v2, 27 Apr 2017). ICALP 2017 venue: UNVERIFIED-MEMORY (not printed
  on retrieved text I checked). VERIFIED_SOURCE for content.
- Def 2.2: theory = well-formed context Σ + set R of rewrite rules well-typed in Σ.
- Thm 3.1 Soundness w.r.t. models valued in Π-algebras; Corollary 3.3 (Consistency): a theory with a model in the
  two-element Π-algebra has no term t with "P : Type ⊢ t : P" derivable.
- §5: "proof reduction terminates in the λΠ-calculus modulo any super-consistent theory such as Simple type theory
  ... or the Calculus of constructions"; "Here, we restrict to prove the termination of β-reduction, not
  βR-reduction." Thm 4.1, 4.2: STT (with/without parametric quantifier) super-consistent; Thm 5.1 termination.
- Relevance (INFERENCE): consistency/termination of an environment is a semantic, per-theory meta-theorem, not

## Synthesis for F01 / F03 / proof identity (INFERENCE, labelled)

1. F01 — Strong partial precedent. One fixed, small kernel (λΠ modulo) + per-logic finite signatures/rules
   covers all functional PTSs (CD2007 schema), predicate logics, STT, CIC fragments; theory U is a SINGLE finite
   environment (38 decl./28 rules) covering ~13 named systems. A project claiming novelty for "fixed finite
   machine + environment, many foundations, derivability preserved and reflected" must show what it adds beyond:
   (a) Dedukti + per-logic signatures; (b) theory U. What these do NOT provide: a fixed environment covering
   inductive types/universes/classical logic as such (U); conservativity of U over each sub-theory at provability
   level (explicitly disclaimed); a general proof-identity theorem; adequacy except Felicissimo's FPTS encoding.
2. F03 — Confirmed. In Dedukti the logic lives in user rules; the kernel checks rule well-typedness
   (approximation) but trusts confluence and termination; consistency/conservativity are paper meta-theorems that
   historically were missing or flawed for major encodings (FW2024 Table 1). Any "environment" design that
   permits user rewrite rules imports this trust gap unless rule admission is restricted to decidable classes
   with proven metatheory.
3. Proof identity — Traditional encodings (CD2007, Assaf 2015): typing and β-steps preserved; inhabitation
   reflected; NO bijection on proofs (CD2007 Remark 1, Examples 4–5); terms only up to framework conversion.
   Felicissimo 2022 Thm 46: bijection mod ≡H on β-normal forms + "M ↪* N iff ⟦M⟧ ↪* ⟦N⟧" for functional EPTS —
   so preservation AND reflection of the object system's reduction is achievable, but by a specific
   annotation-heavy encoding, per-system, only for PTS-like systems. No source addressed cut-equivalence for
   sequent calculi, resource-sensitive or causal structure (R2/R4).
