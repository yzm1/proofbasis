# Research protocol

## Stages and gates

**Stage 0 — existence and novelty:** charter, source-grounded prior-art matrix, definition audit, strongest counterexample, surviving conjecture or stop recommendation. Current stage.

**Stage 1 — reference systems:** choose independent logical traditions and compare established translation/representation baselines. Entry requires Stage 0 acceptance.

**Stage 2 — small mechanized tests:** formalize minimal examples using *existing* frameworks. Every experiment must discriminate between competing precise claims.

**Stage 3 — theorem or obstruction:** attempt a precisely scoped existence, equivalence, or impossibility theorem; independently check central lemmas.

**Stage 4 — peer critique and dissemination:** independent mathematician review, reproduce experiments, publish findings if merited.

No automatic promotion across gates. Negative outcomes can close the project.

## Evidence discipline

For each material assertion record: source author/title/year/location/URL or DOI; exact theorem or passage; hypotheses and quantifiers; whether checked directly; implications and limitations; alternative interpretation.

**Status vocabulary**: VERIFIED_SOURCE (original text inspected), FORMALIZED (proof checker and artifact specified), SECONDARY_ONLY, INFERENCE, CONJECTURE, UNKNOWN, REFUTED. Do not use 'proven' for an agent-written informal derivation.

Prior-art documents list **candidate sources** until consulted. A citation link by itself is not evidence that the described result was read.

## Review roles

- Prior-art agent: strongest existing theorems and detailed hypothesis extraction.
- Adversarial agent: counterexamples, impossibility and vacuity.
- Formalization agent: independently check bounded examples, only after a question warrants it.
- Synthesis agent: maintain contradiction log and epistemic status; cannot self-certify novel theorems.

Independent agents should revisit the same decisive result. Agreement is not formal proof.

## Milestone report format

Executive verdict; scope; explicit claim version; evidence matrix; strongest objection and response; known uncertainty; exact changes proposed to definitions; next discriminating experiment; go/narrow/stop recommendation.

## Implementation restraint

No new implementation unless it addresses a falsifiable question that cannot be resolved by literature and existing tools. No broad autonomous refactoring. Respect budget limits assigned in each task.
